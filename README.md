# SmartStock

Sistema inteligente de gestão de almoxarifado desenvolvido para auxiliar empresas no controle de estoque, inventários, reposição automática e apoio à tomada de decisão.

## Status

🚧 Em desenvolvimento

## Tecnologias previstas

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Streamlit
- Plotly

## Objetivo

Desenvolver uma plataforma capaz de controlar materiais, gerar indicadores e recomendar ações para reduzir perdas e otimizar compras.
